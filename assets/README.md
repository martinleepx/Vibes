## Design Specifications

### App Icon
- Size: 1024x1024px
- Format: PNG with transparency
- Style: Rounded square with the "Free" branding
- Colors: Primary blue (#4A90A4) background with white text

### Splash Screen
- Size: 2048x2048px (centered on various screen sizes)
- Format: PNG with transparency
- Background: Light blue-tinted white (#E8F4F8)
- Content: "Free" logo centered

### Design Guidelines
- Use calming blues and greens
- Rounded, welcoming aesthetic
- Clean and minimal
- Professional but approachable
